## 5. 已确认的核心 Smoke Test

新增测试类：

`backend/src/test/java/com/testpilot/platform/Stage0BaselineSmokeTest.java`

锁定以下迁移前行为：

1. `GET /api/health` 返回 HTTP 200、`code=0`、`data.status=UP`；
2. `POST /api/auth/login` 返回 `data.accessToken` 和用户信息；
3. `Authorization: Bearer <token>` 可以访问 `GET /api/auth/me`；
4. `POST /api/auth/logout` 成功后同一 Token 访问 `/api/auth/me` 返回 `code=40100`；
5. 未携带 Bearer 访问受保护项目接口返回 `code=40100`；
6. 错误用户名或密码返回 `code=40101`。

这组测试不依赖项目数量、异步 AI、Jenkins 外部服务或数据库自增值，适合作为阶段 1-3 的快速回归入口。
