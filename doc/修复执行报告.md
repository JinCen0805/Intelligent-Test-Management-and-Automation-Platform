### A3 AI 异步契约统一（FIX-01）
- **问题**：前端按"提交 → taskId → 轮询"实现，后端三个接口同步返回，导致 AI 失败分析、AI 创建自动化任务在前端必失败（但数据已落库）；`AiTaskService.submit*` 全仓无人调用。
- **改动**：`AiGenerationController`、`AiFailureAnalysisController`、`AiAutomationTaskController` 改为注入 `AiTaskService` 并返回 `AiTaskDtos.SubmitResponse`；前端轮询逻辑保持不动（DTO 已逐字段对齐）；`ApiSmokeTest` 三处改为提交后轮询；删除前端未使用的 `generateTestCases`。
- **验证**：`ApiSmokeTest` 覆盖生成/分析/草稿成功、执行未完成时分析返回失败码 40018、重复分析成功；后端 65/65 全绿；前端构建通过。
- **回滚**：恢复三个 Controller 的同步实现与 `generateTestCases`。

### A4 测试任务表单补齐 environment / branch（FIX-02）
- **问题**：后端 `TestTaskRequest` 对两字段 `@NotBlank`，前端未提交 → 新建/编辑任务必 400。
- **改动**：`TaskModal` 增加执行环境/Branch 输入；`automation` store 表单与编辑回填补齐；`api/automation.ts` 类型与 payload 补齐；`ProjectDetailView` 任务列表新增"环境 / Branch"列。
- **验证**：`npm run build`（vue-tsc）通过。
- **回滚**：回退前端四个文件。

### A5 401 分流：登录失败不再整页刷新（FIX-03）
- **问题**：`handleUnauthorized` 对任何 401 都清 token 并整页刷新，密码错误（后端 401）导致错误提示永远显示不出来。
- **改动**：仅在"401 且存在 token"时清 token/userId 并派发 `testpilot:unauthorized`；`App.vue` 监听事件切回未登录态并回首页，不再 `location.reload()`。
- **验证**：`npm run build` 通过；路径核对：登录 401（无 token）不派发事件、错误可显示；过期 401 走登录态切换。前端单测因暂未引入 Vitest，统一在 D1 补齐 `client.ts` 用例。
- **回滚**：还原 `client.ts`/`App.vue`。

### A6 收紧 `consoleLogRef`，封堵越权读取 Jenkins（FIX-04）
- **问题**：用户可写任意 Jenkins 路径，服务端带 BasicAuth 读取并返回（认证 SSRF）。
- **改动**：`AutomationService` 对外部来源（手工上报、Jenkins 回调）校验 `consoleLogRef` 只允许 `.../job/.../<build>/consoleText`（支持路径或 http(s) URL，拒绝 query/fragment），不合法返回 40043；为空时按 `job + buildNumber` 派生；内部同步/取消路径仍信任服务端同步结果。
- **验证**：`ApiSmokeTest` 新增恶意引用 → 40043、安全路径正常；原有 `mock://` 测试数据改为安全路径；后端 65/65 全绿。
- **回滚**：还原 `saveReport` 校验分支。

### A7 用例编号与项目 code 判重（FIX-06）
- **问题**：`nextCaseNo = count + 1`，删除中间用例后编号冲突；`existsByCode` 被 `@TableLogic` 过滤，复用已删项目 code 会通过校验后撞唯一键 500。
- **改动**：新增 `CaseNoAllocator`（按已用最大编号 +1，跳过占用）；`TestCaseService.create` 改用分配器并在唯一键冲突时重试 3 次，仍冲突返回 40902；`ProjectService.create` 捕获唯一键冲突返回 409。
- **验证**：`CaseNoAllocatorTest` 6 用例；后端 71/71 全绿。
- **回滚**：还原 `TestCaseService`/`ProjectService` 并移除分配器。

### Phase A 结论
- 后端测试从 59 增至 **71**（新增 12 个用例），全绿；前端 `vue-tsc` + `vite build` 通过。
- 遗留到后续阶段：A5 的前端单测在 D1 补；A6 的 `consoleLogRef` 双校验与 Jenkins 侧协议在 B7 扩展。
