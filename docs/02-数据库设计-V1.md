# 数据库设计 V1

## 1. 设计原则

- 只保留支撑 MVP 闭环的核心实体；
- 项目是需求、用例、自动化和报告的业务容器；
- 自动化代码不进入数据库；
- Secret 不以明文保存；
- 所有业务表使用 `id`、`created_at`、`updated_at`；
- 删除优先使用逻辑删除字段 `deleted`。
